DEVA PORTFOLIO WEBSITE

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted Deva_Portfolio folder in Visual Studio Code.
3. Open index.html.
4. Right-click inside index.html and choose "Open with Live Server" if you have the Live Server extension.
   If you do not have Live Server, double-click index.html in File Explorer to open it in your browser.

FILES
- index.html: website content
- style.css: website design
- script.js: menu and footer year
- assets/: add your profile photo here as profile-photo.jpg if you want
